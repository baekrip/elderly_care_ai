## 2. 모델 및 파이프라인 검증 현황

1. **Jetson Orin 모델 동결 및 동등성(Parity) 검증 (PASS)**
   - **ST-GCN TensorRT FP16 Engine**: PyTorch `.pth` -> ONNX -> TensorRT FP16 엔진 (`stgcn_activity_fixed_split_v1_fp16.engine`) 변환 완료.
   - **CUDA Context 안정화**: `pycuda.autoprimaryctx` 적용으로 PyCUDA 사용 시 발생하던 CUDA context corruption(`invalid resource handle`) 오류 완전 해결.
   - **Parity 검증**: 3개 결정론적 입력(`[1, 60, 17, 3]`) 기준 ONNX CPU와 TensorRT FP16 Engine 추론 결과 argmax 100% 일치, max logit difference < 0.0036 검증 완료.
   - **XGBoost 모델 Parity**: 워크스테이션과 Orin 간 동일 모델 SHA-256 (`182bb2ebd4ee84a6fb3b4c30cbf2bf17443477711517336312a008c6f030589c`), 325-feature schema SHA-256 (`f5ede30cb438f75210df1535665d4ea1e7e6e347018a774fde2c8afae57640fd`) 검증 완료.

2. **Raspberry Pi 5 캡처 파이프라인 (PASS)**
   - **카메라 센서**: IMX708 wide 센서 (640x360 30 FPS RGB888 / Raw 1536x864 모드) 정상 작동.
   - **YOLO Pose 추론**: CPU ONNX 파이프라인 동작 지연시간 평균 ~44.9ms ~ 45ms (p95 ~55ms), 추론 속도 ~19-21 FPS (최대 ~23 FPS). 프레임 드롭 0.
   - **RTSP 송출**: FFmpeg 파이프를 이용해 external RTSP (`rtsp://54.116.119.98:8554/P001`)로 실시간 화면 publish 중.

3. **검증 데이터셋 정제 완료 (PASS)**
   - `video/validation` 디렉터리 내 2,272개 MP4 비디오, 2,272개 비디오 JSON, 22,720개 JPG 이미지, 22,720개 이미지 JSON 전체 100% 매칭 확인 (Fall 1,704개 / Normal 568개).
   - 정제 원장 `experiments/behavior_training/manifests/video_validation_dataset_inventory.jsonl` (2,272행) 생성 완료.

## 3. 현재 런타임 오류 및 병목 현상 (Errors & Bottlenecks)

### [병목 1] Pi 카메라 관측 화각 문제 (Camera Scene Bottleneck)
- **현상**: 현재 Pi 5 카메라가 사람이 없는 빈 벽면을 향하고 있음 (`candidate_count=0`, `avg_pose_confidence=0.0`).
- **영향**: 관측 대상(사람)이 없어 실제 pose 키포인트 품질, 관절 흔들림(skeleton jump/fluctuation), ROI 지정 및 실시간 낙상 인지 기능을 시각적으로 검증할 수 없음.
- **조치 필요**: 사람이 등장하는 실제 방 환경 화각 확보 필요.

### [오류 2] WebSocket 단속 재연결 루프 (WebSocket Reconnection Loop)
- **현상**: Pi 5에서 Orin(`192.168.45.110:8000/ws/skeleton/raspi_cam01`)으로 skeleton 데이터를 전송하는 WebSocket 접속이 약 1초 간격으로 `accepted` -> `connection open` -> `connection closed`를 반복하는 현상 관측.
- **원인**: 사람이 없어 빈 skeleton batch가 지속 전송되거나 클라이언트 수신 타임아웃/소켓 조기 종료 로직 발동.
- **영향**: 네트워크 핸드셰이크 트래픽 낭비 및 Orin 서비스 로그 오염.

### [오류 3] RTSP 송출 파이프 끊김 (RTSP Broken Pipe Error)
- **현상**: Pi 5의 FFmpeg RTSP 송출 파이프에서 외부 미디어 서버 (`54.116.119.98:8554`) 접속 재설정 시 `Error submitting a packet to the muxer: Broken pipe` (Error code -32) 지속 로그 발생.
- **원인**: 외부 RTSP 미디어 서버와의 세션 커넥션 유실 또는 네트워크 지연으로 인한 소켓 파이프 단절.

### [병목 4] Pi 5 CPU YOLO Pose FPS 한계 (Pose FPS Limit)
- **현상**: Pi 5 CPU 환경에서 YOLO pose 키포인트 추출 지연시간이 프레임당 약 44.9ms로 물리적 한계 (~21 FPS) 존재.
- **영향**: 끊김 없는 30 FPS 실시간 처리를 위해서는 프레임당 33.3ms 이하가 필요하나, CPU 파이프라인 미세조정만으로는 30 FPS 완벽 보장이 어려움.

### [게이트 5] 외부 Validation 정답 라벨 및 예측 미생성 (Validation Predictions Blocked)
- **현상**: `video/validation` 디렉터리의 2,272개 비디오 데이터에 대해 외부 최종 검증 예측 JSONL이 아직 생성되지 않음.
- **상태**: 외부 최종 판정 기준(`fall` vs `normal`)의 정확도 보고서 완성을 위해 모델 예측 생성이 필요한 `BLOCKED_MODEL_PREDICTIONS_REQUIRED` 게이트 대기 중.

## 4. 남아있는 핵심 작업 및 차단 게이트 (Open Gates & Next Steps)

1. **실제 사람 화각 확보 및 Skeleton / ROI 수동 입력**
   - 사람이 등장하는 카메라 화면 확보 후 Pose 키포인트 품질 및 skeleton jump 상태 점검.
   - Flask 수동 ROI 도구 (`tools/manual_roi_flask.py`)를 통해 해당 방의 `bed`, `floor`, `chair` polygon 지정 및 저장.

2. **`video/validation` 검증셋 최종 batch 예측 및 보고서 작성**
   - 2,272개 validation 비디오에 대해 배치 추론 수행.
   - 최종 서비스 판정 범위인 `fall`과 `normal` 2-class에 대한 confusion matrix, precision, recall, F1-score 정량 산출.

3. **Orin Shadow Mode 장시간 검증 (Soak Test)**
   - 최소 24시간 이상 Shadow mode 구동을 통한 메모리 누수, WebSocket 안정성, 커넥션 유지 검증.

4. **최종 운영 알림 승격 (Production Cutover)**
   - 위 1~3단계 게이트가 모두 정상 통과되고 사용자 승인이 완료된 경우에만 Orin 알림(`alerts_enabled=true`) 및 생산 서비스 전환 진행.
