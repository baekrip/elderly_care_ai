# 수정사항.md

## 목적

현재 독거노인 케어 AI 프로젝트에서 Pi5, Jetson Orin Nano, EC2 백엔드 연동 방식을 다음 기준으로 정리하고 코드에 반영한다.

- 실제 secret 값은 YAML에 하드코딩하지 않고 `.env`에서 로드한다.
- EC2 외부 IP는 가변이므로 실행할 때마다 `export`로 입력한다.
- Pi5 영상 RTSP 송출은 EC2 MediaMTX로 보낸다.
- Pi5 skeleton WebSocket 전송은 Orin FastAPI Edge Hub로 보낸다.
- Orin 분석 결과 ingest는 EC2 Flask 백엔드 REST API로 보낸다.
- 백엔드에는 WebSocket endpoint가 없으며, 실시간 알림은 SSE `/api/v1/alerts/stream`만 사용한다.
- 백엔드는 영상 overlay를 합성하지 않는다. Overlay는 1차 AI 또는 프론트엔드 canvas 영역에서 처리한다.

## 1. 전체 통신 경로 확정

### 1.1 Pi5 실시간 영상 송출

Pi5 카메라 영상은 EC2의 MediaMTX로 RTSP push한다.

```text
Pi5 edge.main
→ rtsp://<EC2_IP>:8554/patient_test
→ EC2 MediaMTX
→ Frontend viewer: http://<EC2_IP>:8889/patient_test/
```

실행 시 Pi5에서 아래처럼 IP만 입력한다.

```bash
export EC2_STREAM_HOST="13.209.89.107"
```

코드가 자동으로 아래 값을 생성해야 한다.

```text
stream.output_url  = rtsp://13.209.89.107:8554/patient_test
camera.stream_url  = http://13.209.89.107:8889/patient_test/
```

### 1.2 Pi5 skeleton 전송

Pi5는 skeleton 좌표를 Orin으로 WebSocket 전송한다.

```text
Pi5
→ ws://192.168.45.241:8000/ws/skeleton/raspi_cam01
→ Orin FastAPI Edge Hub
```

### 1.3 Orin 분석 결과 백엔드 전송

Orin은 EC2 Flask backend REST API로 이벤트와 알림을 전송한다.

```text
Orin
→ http://<EC2_IP>:5000/api/v1/events/batch
→ http://<EC2_IP>:5000/api/v1/alerts/immediate
```

실행 시 Orin에서 아래처럼 IP를 입력한다.

```bash
export BACKEND_BASE_URL="http://13.209.89.107:5000"
```

### 1.4 Clip 흐름

위험 clip은 MediaMTX가 아니라 REST/S3 흐름으로 처리한다.

```text
Orin 또는 Pi5
→ POST /api/v1/clips/upload-url
→ S3 presigned PUT
→ POST /api/v1/clips/confirm
```

Pi5/Orin 내부의 MediaMTX는 clip 전송용이 아니다. MediaMTX는 실시간 RTSP/WebRTC fanout 용도다.

### 2.1 Orin `.env`

경로:

```text

```

내용 예시:

```env
APP_TOKEN=project-eagle-eye-porm
```

### 2.2 Pi5 `.env`

경로:

```text
/home/eagleeye/elderly_care_ai/.env
```

```env

CLIP_UPLOAD_API_KEY=CLIP_KEY
EDGE_CLIP_REQUEST_API_KEY=CLIP_REQ_KEY
```

Pi5에는 `APP_TOKEN`, `BACKEND_BASE_URL`이 필요 없다.  
`APP_TOKEN`과 `BACKEND_BASE_URL`은 Orin이 EC2 백엔드로 보낼 때만 사용한다.

## 4. `server/main.py` 수정

### 4.3 `.env` 로더 추가

`ResultArchive` import 아래에 추가한다.

```python
def _load_project_dotenv() -> None:
    project_root = Path(__file__).resolve().parents[1]
    dotenv_path = project_root / ".env"

    if not dotenv_path.exists():
        return

    for raw_line in dotenv_path.read_text(encoding="utf-8").splitlines():
        line = raw_line.strip()

        if not line or line.startswith("#") or "=" not in line:
            continue

        key, value = line.split("=", 1)
        key = key.strip()

        if key.startswith("export "):
            key = key[len("export "):].strip()

        if not key:
            continue

        value = value.strip()

        if len(value) >= 2 and value[0] == value[-1] and value[0] in {"'", '"'}:
            value = value[1:-1]

        os.environ.setdefault(key, value)
```

수정 전:

```python

```

수정 후:

```python

```

### 4.5 실행 방식 주의

Orin 서버는 아래 방식으로 실행해야 한다.

```bash
PYTHONPATH=. .venv_edge/bin/python -m server.main \
  --config server/config.orin.yaml \
  --host 0.0.0.0 \
  --port 8000
```

아래 방식은 사용하지 않는다.

```bash
python -m uvicorn server.main:app --host 0.0.0.0 --port 8000
```

이 방식은 `app = create_app()`의 기본 config인 `server/config.yaml`로 뜰 수 있어서 `server/config.orin.yaml`이 적용되지 않을 위험이 있다.

## 5. `server/services/backend_forwarder.py` 수정

### 5.1 목적

- `BACKEND_BASE_URL`은 실행 시 `export`된 환경변수만 사용한다.
- `APP_TOKEN`은 `.env` 또는 export된 환경변수만 사용한다.
- `config.orin.yaml`의 `backend.base_url`, `backend.token`은 fallback으로 사용하지 않는다.
- URL이 없으면 backend forwarder는 비활성화한다.
- URL은 있는데 token이 없으면 명시적으로 오류를 낸다.

### 5.2 `config_from_project_config()` 교체

```python
def config_from_project_config(project_config: dict[str, Any]) -> BackendConfig:
    backend = project_config.get("backend", {}) or {}

    base_url = str(
        os.getenv("BACKEND_BASE_URL")
        or os.getenv("AI_BACKEND_BASE_URL")
        or ""
    ).strip().rstrip("/")

    token = str(
        os.getenv("APP_TOKEN")
        or os.getenv("BACKEND_APP_TOKEN")
        or ""
    ).strip()

    backend_enabled = bool(backend.get("enabled", False))
    enabled = backend_enabled and bool(base_url)

    if backend_enabled and base_url and not token:
        raise ValueError(
            "BACKEND_BASE_URL은 설정됐지만 APP_TOKEN이 없습니다. "
            "/home/eagleeye/elderly_care_ai/.env에 APP_TOKEN=토큰값 을 넣으세요."
        )

    return BackendConfig(
        enabled=enabled,
        base_url=base_url,
        token=token,
        events_batch_path=str(backend.get("events_batch_path", "/api/v1/events/batch")),
        alerts_immediate_path=str(backend.get("alerts_immediate_path", "/api/v1/alerts/immediate")),
        batch_interval_sec=float(backend.get("batch_interval_sec", 10.0)),
        normal_batch_interval_sec=float(backend.get("normal_batch_interval_sec", 300.0)),
        request_timeout_sec=float(backend.get("request_timeout_sec", 10.0)),
        pending_file=str(backend.get("pending_file", "server/storage/results/backend_pending.jsonl")),
        contract_error_file=str(backend.get("contract_error_file", "server/storage/results/backend_contract_errors.jsonl")),
        max_pending_events=int(backend.get("max_pending_events", 10000)),
        max_pending_age_hours=float(backend.get("max_pending_age_hours", 24.0)),
    )
```

```python
def _load_project_dotenv() -> None:
    candidates = [
        Path(__file__).resolve().parents[1] / ".env",
        Path.cwd() / ".env",
    ]

    for dotenv_path in candidates:
        if not dotenv_path.exists():
            continue

        for raw_line in dotenv_path.read_text(encoding="utf-8").splitlines():
            line = raw_line.strip()

            if not line or line.startswith("#") or "=" not in line:
                continue

            key, value = line.split("=", 1)
            key = key.strip()

            if key.startswith("export "):
                key = key[len("export "):].strip()

            if not key:
                continue

            value = value.strip()

            if len(value) >= 2 and value[0] == value[-1] and value[0] in {"'", '"'}:
                value = value[1:-1]

            os.environ.setdefault(key, value)

        return


def _override_secret_from_env(
    section: dict[str, Any],
    *,
    value_key: str,
    env_key: str,
    default_env_name: str,
) -> None:
    env_name = str(section.get(env_key) or default_env_name).strip()
    value = os.getenv(env_name, "").strip()
    if value:
        section[value_key] = value


def _normalize_host_only(value: str) -> str:
    normalized = str(value or "").strip()
    normalized = normalized.replace("rtsp://", "")
    normalized = normalized.replace("http://", "")
    normalized = normalized.replace("https://", "")
    normalized = normalized.strip("/")
    return normalized


def apply_runtime_env_overrides(config: dict[str, Any]) -> None:
    ec2_stream_host = _normalize_host_only(os.getenv("EC2_STREAM_HOST", ""))

    if ec2_stream_host:
        config.setdefault("stream", {})
        config["stream"]["output_url"] = f"rtsp://{ec2_stream_host}:8554/patient_test"

        config.setdefault("camera", {})
        config["camera"]["stream_url"] = f"http://{ec2_stream_host}:8889/patient_test/"

        LOGGER.info("stream.output_url set from EC2_STREAM_HOST")
        LOGGER.info("camera.stream_url set from EC2_STREAM_HOST")

    rtsp_output_url = os.getenv("RTSP_OUTPUT_URL", "").strip()
    if rtsp_output_url:
        config.setdefault("stream", {})
        config["stream"]["output_url"] = rtsp_output_url
        LOGGER.info("stream.output_url overridden by RTSP_OUTPUT_URL")

    camera_stream_url = os.getenv("CAMERA_STREAM_URL", "").strip()
    if camera_stream_url:
        config.setdefault("camera", {})
        config["camera"]["stream_url"] = camera_stream_url
        LOGGER.info("camera.stream_url overridden by CAMERA_STREAM_URL")

    server_cfg = config.setdefault("server", {})
    _override_secret_from_env(
        server_cfg,
        value_key="ingest_api_key",
        env_key="ingest_api_key_env",
        default_env_name="EDGE_INGEST_API_KEY",
    )
    _override_secret_from_env(
        server_cfg,
        value_key="clip_upload_api_key",
        env_key="clip_upload_api_key_env",
        default_env_name="CLIP_UPLOAD_API_KEY",
    )

    clip_request_cfg = config.setdefault("clip_request_server", {})
    _override_secret_from_env(
        clip_request_cfg,
        value_key="api_key",
        env_key="api_key_env",
        default_env_name="EDGE_CLIP_REQUEST_API_KEY",
    )
```

## 8. ONNX Runtime 경고 완화

Pi5에서 다음 경고가 발생할 수 있다.

```text
Failed to detect devices under "/sys/class/drm/card..."
```

기능 장애 원인은 아니지만, 로그를 줄이려면 ONNX Runtime session 생성 코드에서 CPU provider를 명시하고 log severity를 조정한다.

`edge/pose_estimator.py` 또는 ONNX `InferenceSession` 생성 위치에서 아래 형태로 수정한다.

```python
import onnxruntime as ort

session_options = ort.SessionOptions()
session_options.log_severity_level = 3

self.session = ort.InferenceSession(
    model_path,
    sess_options=session_options,
    providers=["CPUExecutionProvider"],
)
```

## 12. 503 지속 시 우선 점검

`/api/cameras/register`가 계속 503이면 아래 순서로 확인한다.

1. Orin `server/main.py`에 `_load_project_dotenv()`가 실제 반영됐는지 확인한다.
2. Orin 서버를 `uvicorn server.main:app`로 실행하지 않았는지 확인한다.
3. 반드시 `python -m server.main --config server/config.orin.yaml`로 실행한다.
4. `server/config.orin.yaml`의 `ingest_auth.api_key`가 빈 문자열인지 확인한다.
5. `server/config.orin.yaml`의 `ingest_auth.api_key_env`가 `EDGE_INGEST_API_KEY`인지 확인한다.
6. Pi5 `edge/config.raspi_cam01.yaml`의 `server.ingest_api_key`가 빈 문자열인지 확인한다.
7. Pi5와 Orin의 `EDGE_INGEST_API_KEY` 길이와 값이 동일한지 확인한다.
8. 헤더명은 YAML 키 이름이 아니라 실제 값이 같아야 한다.

정상 예시:

```yaml
# Orin
api_key_header: "X-Edge-API-Key"

# Pi5
ingest_api_key_header: "X-Edge-API-Key"
```

`api_key_header`와 `ingest_api_key_header`처럼 YAML 필드명은 달라도 된다. 실제 HTTP 헤더 값인 `"X-Edge-API-Key"`가 같으면 된다.
